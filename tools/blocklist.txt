# The source lexicon (SCOWL) is a spell-checker word list — it is complete,
# not curated, and contains plenty of vocabulary that is fine in a dictionary
# and wrong in a casual word game. Left unfiltered the generator will happily
# place slurs, sexual terms, and violence vocabulary in a grid, because they
# are simply valid sub-anagrams.
#
# One entry per line, lowercase. Matching is exact against whole words, and is
# also applied to bonus-word candidates, so a blocked word can neither be
# placed nor scored.
#
# Deliberately conservative: a few false positives (harmless words excluded)
# cost nothing here, since level content is unlimited and interchangeable.
# A single false negative in a demo is a serious problem.
